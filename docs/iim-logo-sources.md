# IIM logo source record

Checked: 27 October 2026.

The 22-institution roster combines the 21 IIMs listed in the official [CAT 2025 information bulletin](https://www.iima.ac.in/sites/default/files/2025-08/Information_Bulletin.pdf) with [IIM Guwahati](https://www.iimg.ac.in/the-institute/), whose official institute page identifies it as the 22nd IIM. The roster includes IIM Mumbai and IIM Guwahati.

These files are original institutional logo artwork, self-hosted for institution identification. Twenty-one were downloaded from the relevant institution’s own domain. IIM Bangalore uses the publicly accessible preview from the [National Informatics Centre logo directory](https://www.uxdt.nic.in/documents/iim/iim-bangalore/), because automated requests to its institutional website returned HTTP 403. No login-only artwork was accessed.

Files were not redrawn, generated, recoloured or cropped. Raster and SVG dimensions below reflect the downloaded files. Full wordmarks were selected instead of cropped thumbnails or headers containing separate accreditation marks. Names and logos identify institutions; this source record does not establish endorsement or independently verify Neorons programme activity.

All three SVGs were inspected for scripts, foreignObject elements, event handlers and remote asset references. None contains active content or remote dependencies. The Ahmedabad SVG includes an embedded PNG data URI.
